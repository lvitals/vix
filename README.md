# vix

vix is a screen-oriented text editor combining vi-style modal editing with
Plan 9 sam-style structural regular expressions and multiple selections.

The main user manual is available in `docs/vix.md` and as the `vix(1)` man
page.

## Build System

vix uses Autotools. Source checkouts are bootstrapped with:

```sh
./autogen.sh
```

After bootstrapping, configure and build with:

```sh
./configure
make
```

Run the test suite with:

```sh
make test
```

Install with:

```sh
make install
```

Use the standard Autotools variables when needed:

```sh
./configure --prefix=/usr/local
make DESTDIR=/tmp/package-root install
```

## Required Build Tools

A normal build from a source checkout needs:

- a C99 compiler
- `make`
- Autoconf
- Automake
- `pkg-config`

Release tarballs generated by Autotools may already include `configure`, in
which case Autoconf and Automake are not required by end users.

## Runtime and Build Dependencies

Dependency package names vary across systems. Prefer searching for the file,
library, or `pkg-config` module listed below instead of relying on a specific
package name.

Required by the default build:

- Lua development files
  - `pkg-config` module: `lua` by default
  - headers and library for the selected Lua installation
  - a matching Lua interpreter available in `PATH`
- LPeg for the same Lua installation
  - Lua module: `require("lpeg")`
  - linkable shared object exporting `luaopen_lpeg`
- TRE development files
  - `pkg-config` module: `tre`
  - header: `tre/tre.h`
  - library: `libtre`

Built-in local code provides the key parser previously supplied by
`libtermkey`; no external `termkey` package is required.

Optional dependencies:

- ncursesw development files, only when `--enable-curses` is used
  - `pkg-config` module: `ncursesw`
  - header: `curses.h`
  - library: `libncursesw`
- POSIX ACL development files, only when `--enable-acl` is used
  - header: `sys/acl.h`
  - library providing `acl_get_file`
- SELinux development files, only when `--enable-selinux` is used
  - header: `selinux/selinux.h`
  - library providing `getfilecon`

## Configure Options

Feature options:

```sh
--disable-lua        disable Lua support
--with-lua-pkg=NAME  use a specific Lua pkg-config module
--disable-tre        disable TRE regular expression support
--enable-curses      enable the ncursesw terminal backend
--enable-acl         enable POSIX ACL support
--enable-selinux     enable SELinux support
```

Build options:

```sh
--enable-debug       build with debug flags
--enable-asan        build with AddressSanitizer
```

Examples:

```sh
./configure --disable-lua
./configure --disable-tre
./configure --with-lua-pkg=lua
./configure --enable-curses
./configure --enable-debug --enable-asan
```

## Key Input

vix includes a local C key parser in `termkey.c` and `termkey.h`. This code is
compiled into the editor and replaces the previous external `libtermkey`
dependency. Do not install a separate `termkey` package for this build.

The local key parser is responsible for:

- raw terminal input setup and restoration
- printable UTF-8 input
- control, alt, and shift modifiers
- common special keys such as arrows, Home, End, PageUp, PageDown, Insert,
  Delete, Backspace, Tab, Enter, Escape, and function keys
- unknown CSI sequences used by terminal event handling

## Runtime Helpers

Several editor features use helper programs and scripts:

- `vix-menu`
- `vix-complete`
- `vix-open`
- `vix-clipboard`
- `vix-digraph`

When installed, these helpers are placed in the configured binary directory.
When running directly from a build tree, keep the helpers next to the `vix`
binary. At startup, vix prepends the directory containing its own executable to
`PATH`, so completion and prompt selection can find the build-tree helpers.

## Dependency Troubleshooting

If `configure` reports that Lua is missing, install the Lua interpreter and
development files for the Lua installation you want to build against. If the Lua
`pkg-config` module is not named `lua`, pass the module name explicitly:

```sh
./configure --with-lua-pkg=NAME
```

If `configure` reports that LPeg is missing, install the LPeg module for the
same Lua installation selected by the build. The check is equivalent to:

```sh
lua -e 'require("lpeg")'
```

If `configure` reports that TRE is missing, install the TRE development package
that provides `tre.pc`, `tre/tre.h`, and `libtre`. If TRE support is not needed:

```sh
./configure --disable-tre
```

If a dependency is installed in a non-standard prefix, set the appropriate
`pkg-config` search path before configuring:

```sh
PKG_CONFIG_PATH=/custom/prefix/lib/pkgconfig ./configure
```

## Installed Files

The build installs:

- binaries: `vix`, `vix-menu`, `vix-digraph`
- helper scripts: `vix-clipboard`, `vix-complete`, `vix-open`
- man pages from `man/`
- Lua runtime files from `lua/` into the configured data directory

By default, Lua runtime files are installed under:

```text
${prefix}/share/vix
```
